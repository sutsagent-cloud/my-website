SL2100
SL2100內建的功能包含：
來電顯示
日間/夜間模式
網頁型整合通訊
VoIP功能
語音訊息
保留音樂
行動/BYOD/遠端分機
自動總機
多方語音會議
視訊會議及協同
IP話機
支援Gagabit速率(全雙功)
8個可程式鍵(可翻頁,最多至32鍵)
可程式按鍵標籤
PoE供電
主機端須提供固定IP
本公司提供專業安裝及維護服務，歡迎來電洽詢
規格:
1.3外線8內線
2.6外線16內線
3.4外線8內線
4.單機櫃最大可以12外線，32分機
5.具備 (12 鍵 / 24 鍵) 兩種形式
SL2100 提供兩款話機：數位型話機 與 IP 話機。
其中，數位型話機提供12/24按鍵兩種選擇。IP 話機 ，只需透過代號驗證 (登入 / 登出)，即可立即變換辦公座位接聽電話。
數位話機規格　
1.外觀顏色  黑色
2.LCD 顯示幕16 字元 x 2 列  無背光
3.可程式鍵數目   12/24 (BLF : 紅/綠)
4.軟體鍵  無
5.目錄游標選擇鍵  有
6.來電指示    LED2 色 (紅/綠)
7.免持對講     半雙工
8.撥號鍵背光   無
9.照度感知    無
10.耳機接座   No (use Handset Port)
11.PC 網路孔    無
12.高度調整腳座2-階    (低/高)
13.掛壁   可
IP 話機規格　
1.連線方式   LAN
2.供電方式   Only PoE
3.外觀顏色  黑色
4.LCD 顯示幕168 x 128 點 有背光
5.可程式鍵數目8 (BLF :紅/綠)
6.軟體鍵有,4個
7.目錄游標選擇鍵  有
8.來電指示 LED3 色 (紅/綠/黃)
9.免持對講  全雙工
10.撥號鍵背光  無
11.耳機接座   有
12.PC 網路孔Yes (10M/100M/1000M x 1)
13.高度調整腳座2-階   (低/高)
14.掛壁 可
15.Support CODEC  G.711/G.729a
